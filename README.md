# byteforge-atari-adventure

ByteForge Foundry dogfood: Atari 2600 Adventure (Robinett, 1980) homage in Python pygame. Built end-to-end by the v5 chain.

## Installation

Install dependencies:

```bash
pip install -r requirements.txt
```

## Running the Game

```bash
python adventure.py
```

## Running Tests

```bash
pytest
```
